# 光影志 · Light & Shadow

> 一本在暗房里翻阅的互动光影美学科普杂志。拖光、看影、懂明暗，然后在拍照、穿搭、生活里用出来。

**在线阅读**：https://tom61-bl.github.io/light-shadow/

## 这是什么

「光影志」是美学杂志系列的第三本，与「字体志」「色彩志」并列：

- **字体志**讲「字」——typography
- **色彩志」讲「色」——color
- **光影志」讲「光」——light & shadow

光是色彩的前提：没有光，就没有色，也没有形。

## 技术

- 纯前端，零构建，GitHub Pages 直接部署
- 核心布光模拟使用 [Three.js](https://threejs.org/)
- 其余交互使用原生 Canvas 2D
- 模块化：`css/` 样式、`js/` 按章节分文件

## 本地运行

直接用浏览器打开 `index.html`，或启动一个本地服务器：

```bash
python -m http.server 8000
# 访问 http://localhost:8000
```
